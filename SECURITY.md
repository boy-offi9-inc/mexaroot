# Security policy

## Reporting a vulnerability

Report vulnerabilities privately through GitHub's "Report a vulnerability" option on the Security tab of this repository. Do not open a public issue.

Include the affected version, steps to reproduce, and the impact you observed. You will receive an acknowledgment, and fixes are coordinated with the reporter before disclosure.

## Scope

Reports are in scope for authentication and token handling, transport security, command execution, file operations, and anything that exposes the daemon beyond its intended interface.

## Supported versions

Security fixes are provided for the latest release.
